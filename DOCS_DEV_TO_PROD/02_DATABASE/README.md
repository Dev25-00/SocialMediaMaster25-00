# 💾 BASE DE DONNÉES

## Structure et Scripts SQL

Ce dossier contient tous les scripts de base de données nécessaires pour :

- **database.sql** : Structure initiale de la base
- **database-updates-v2.sql** : Mises à jour et migrations  
- **smm_master_UPTODATE_STRUCTURE.sql** : Structure complète à jour

### Utilisation
1. Importer `database.sql` pour l'installation initiale
2. Appliquer `database-updates-v2.sql` pour les mises à jour
3. Utiliser la structure complète si besoin de réinstallation
