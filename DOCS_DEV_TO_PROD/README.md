## 📁 ARCHITECTURE DE LA DOCUMENTATION

Cette documentation est organisée selon une structure logique pour faciliter les sessions de développement quotidiennes et le suivi de progression du projet.

### 🎯 01_PROJECT_MANAGEMENT

**Gestion de projet et suivi**

- **progress/** - États d'avancement et rapports de progression
- **planning/** - Plans d'action, checklists et planifications
- **core_docs/** - Documentation projet principale (README, CHANGELOG)

### 💾 02_DATABASE

**Scripts et structures de base de données**

- Fichiers SQL de création et mise à jour de la base de données
- Structures de tables et données de test

### ⚙️ 03_INSTALLATION_SETUP

**Configuration et installation**

- Guides de configuration API
- Instructions de déploiement initial

### 🛠️ 04_DEVELOPMENT_GUIDES

**Guides de développement**

- **installation/** - Guides d'installation (WAMP, Quick Start, etc.)
- **payment/** - Guides de paiement (PayPal, Stripe, Sandbox)
- **services_module/** - Documentation complète du module Services (grille, filtres, modal, regex)
- **testing/** - Guides de test (CSS, Footer, etc.)

### 🔧 05_FIXES_PATCHES

**Corrections et patchs**

- **css/** - Corrections CSS et responsive
- **links/** - Corrections de liens et footer
- **emojis/** - Remplacement d'emojis
- Autres correctifs généraux

### 🚀 06_DEPLOYMENT

**Déploiement et mise en production**

- Guides de déploiement
- Guides de finalisation
- Checklists de mise en production

### 📋 07_BACKUP_LOGS

**Sauvegardes et logs**

- Fichiers de sauvegarde
- Logs d'opérations
- Historiques de modifications

---

## 🔍 NAVIGATION RAPIDE

### Pour une nouvelle session de développement :

1. **Consulter** : `01_PROJECT_MANAGEMENT/progress/` pour l'état actuel
2. **Planifier** : `01_PROJECT_MANAGEMENT/planning/` pour les prochaines étapes
3. **Développer** : `04_DEVELOPMENT_GUIDES/` selon la tâche
4. **Corriger** : `05_FIXES_PATCHES/` pour appliquer les corrections

### Pour un déploiement :

1. **Vérifier** : `06_DEPLOYMENT/` pour les guides
2. **Base de données** : `02_DATABASE/` pour les scripts SQL
3. **Configuration** : `03_INSTALLATION_SETUP/` pour la config

---

## 📝 CONVENTIONS

- **Fichiers MD** : Documentation markdown
- **Fichiers SQL** : Scripts de base de données
- **Fichiers PHP** : Scripts de sauvegarde/migration
- **Fichiers TXT** : Logs et historiques

**Note :** Cette structure facilite la maintenance, le développement collaboratif et le suivi de progression du projet SMM Mastery.
