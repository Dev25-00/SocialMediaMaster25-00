## 🚀 ÉTAPES POUR METTRE EN LIGNE

### Étape 1 : Préparer l'Hébergement (15 min)

#### Choisir un Hébergeur

**Recommandations :**

- **o2switch** (France) : 5€/mois - Excellent rapport qualité/prix
- **Hostinger** : 3-7€/mois - Économique
- **DigitalOcean** : VPS 20€/mois - Plus performant

**Spécifications minimum :**

- PHP 8.0+
- MySQL 8.0+
- SSL inclus
- 50GB stockage
- Accès SSH (recommandé)

#### Acheter un Domaine

- **Namecheap** : ~10$/an
- **OVH** : ~10€/an
- **GoDaddy** : Variable

Exemples de noms :

- smmmaster.com
- smmgrowth.io
- socialboosting.com

### Étape 2 : Upload des Fichiers (10 min)

#### Via FTP (Simple)

```
1. Téléchargez FileZilla
2. Connectez-vous avec les identifiants FTP
3. Uploadez tout le dossier smm-Mastery/ dans public_html/
4. Attendez la fin du transfert
```

#### Via SSH (Plus rapide)

```bash
# Se connecter au serveur
ssh user@votreserveur.com

# Se placer dans le dossier web
cd /var/www/html

# Cloner ou copier les fichiers
# (Si vous avez Git)
git clone votre-repo.git
```

### Étape 3 : Configuration Permissions (2 min)

```bash
# Permissions standard
chmod 755 -R .

# Dossiers en écriture
chmod 777 logs uploads

# Fichier config (sera créé par install.php)
chmod 644 config.php
```

### Étape 4 : Installation (5 min)

1. Ouvrez votre navigateur
2. Allez sur : `https://votredomaine.com/install.php`
3. Suivez les 4 étapes automatiques :

   - ✅ Vérification prérequis
   - ✅ Configuration base de données
   - ✅ Création des tables
   - ✅ Création compte admin

4. **IMPORTANT** : Supprimez `install.php` après !

```bash
rm install.php
# ou via FTP, supprimez le fichier
```

### Étape 5 : Configuration Initiale (10 min)

#### 1. Connectez-vous

- URL : `https://votredomaine.com/auth/login.php`
- Username : `admin`
- Password : `Admin@123`

#### 2. Changez le mot de passe

- Dashboard > Profil
- Changez immédiatement `Admin@123`

#### 3. Configurez SMMFollows

- Allez sur https://smmfollows.com
- Créez un compte
- Ajoutez du solde (min $20 pour tester)
- Récupérez votre API Key
- Admin > Paramètres > Entrez l'API Key

#### 4. Lancez la première synchronisation

```bash
# Via SSH
php /chemin/vers/cron/sync-services.php

# Ou via navigateur (première fois seulement)
https://votredomaine.com/cron/sync-services.php?cron_key=test
```

### Étape 6 : Configuration CRON (5 min)

```bash
# Éditez le crontab
crontab -e

# Ajoutez ces lignes
0 */6 * * * php /var/www/html/smm-Mastery/cron/sync-services.php
*/10 * * * * php /var/www/html/smm-Mastery/cron/check-orders.php

# Sauvegardez (Ctrl+X, Y, Enter)
```

### Étape 7 : SSL/HTTPS (5 min)

```bash
# Installer Certbot (Let's Encrypt)
sudo apt install certbot python3-certbot-apache

# Obtenir le certificat SSL (gratuit)
sudo certbot --apache -d votredomaine.com -d www.votredomaine.com

# Renouvellement automatique
sudo certbot renew --dry-run
```

## 🆘 SUPPORT ET AIDE

### Problèmes Courants

**Services vides ?**

```bash
php cron/sync-services.php
```

**Erreur BDD ?**

- Vérifiez `config.php`
- Testez : `mysql -u user -p`

**Erreur 500 ?**

- Activez `DEBUG_MODE` dans config.php
- Vérifiez logs : `tail -f /var/log/apache2/error.log`

**CRON ne marche pas ?**

- Vérifiez chemins absolus
- Testez manuellement les scripts
