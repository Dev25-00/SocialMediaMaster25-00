🔑 2. Gestion des Clés API

Test: Affichage de la section API

Vérifiez que la section "Clé API pour développeurs" est présente dans le profil.

Ouvrir Profil

Test: Génération d'une clé

Étapes:

  1. Cliquez sur "Générer une clé API"
  2. Vérifiez que la clé s'affiche (64 caractères hexadécimaux)
  3. Cliquez sur le bouton "Copier"
  4. Vérifiez que le feedback "Copié !" s'affiche
  5. Collez dans un éditeur pour vérifier

Test: Régénération

Étapes:

  1. Copiez la clé actuelle
  2. Cliquez sur "Régénérer"
  3. Confirmez dans le popup
  4. Vérifiez que la nouvelle clé est différente
  5. Vérifiez que l'ancienne clé ne fonctionne plus (test API)

Test: Suppression

Étapes:

  1. Cliquez sur "Supprimer"
  2. Confirmez dans le popup
  3. Vérifiez que le message "Vous n'avez pas encore de clé API" s'affiche
  4. Vérifiez que le bouton "Générer une clé API" est présent

Exécutez cette requête SQL pour vérifier:
